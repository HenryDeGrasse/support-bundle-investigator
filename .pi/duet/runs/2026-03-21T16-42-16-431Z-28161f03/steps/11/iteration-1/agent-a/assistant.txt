What the new tests cover:
1. **Corrupt archive**
   - writes non-gzip bytes to a `.tar.gz`
   - asserts `extractBundle()` rejects with a real error and non-empty message

2. **Truncated archive**
   - creates a valid archive, truncates it mid-stream
   - asserts extraction fails gracefully with a meaningful error

3. **Empty archive**
   - creates an archive containing only an empty directory entry, resulting in zero extracted files
   - asserts `analyzeBundlePipeline()` completes with:
     - 0 manifest files
     - 0 artifact counts
     - 0 findings

4. **Missing expected files**
   - creates a bundle with only `analysis.json`
   - asserts pipeline completes with partial analyzer-only results and no crash

5. **Malformed YAML/JSON**
   - creates one malformed resource YAML plus one valid resource YAML
   - asserts the bad file is skipped and the valid resource still parses

6. **Binary file in bundle**
   - creates a bundle containing `analysis.json` plus a `.png`
   - asserts the profiler classifies the `.png` as `unknown`
   - asserts pipeline parsing ignores it
