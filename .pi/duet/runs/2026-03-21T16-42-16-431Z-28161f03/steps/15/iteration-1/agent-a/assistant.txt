What I changed:
- Added diagnostics types to `src/reporters/types.ts`:
  - `PipelineStepTiming`
  - `ConfidenceHistogram`
  - `InvestigationDiagnostics`
  - optional `diagnostics?: InvestigationDiagnostics` on `InvestigationReport`

- Extended `src/reporters/report-builder.ts`:
  - added `BuildReportOptions`
    - `includeDiagnostics?: boolean`
    - `trace?: InvestigationTrace`
  - diagnostics now derive from trace + findings:
    - pipeline step timings
    - seed count / category breakdown
    - retrieval stats
    - confidence stats
    - confidence histogram
    - hypothesis stats + conversion rate
    - AI summary
  - `buildReport()` now supports explicit trace override and gated diagnostics inclusion

- Updated `src/reporters/json-reporter.ts`
  - emits top-level `diagnostics` when present
  - preserves existing top-level `aiSummary`

- Updated `src/reporters/markdown-reporter.ts`
  - added Diagnostics section rendering with:
    - pipeline step timings
    - seed count by category
    - finding confidence histogram
    - hypothesis conversion rate
    - retrieval stats
    - AI call stats when AI was used
  - rendering is optional based on report diagnostics presence and can be suppressed with `includeDiagnostics: false`

- Updated `src/cli/output.ts`
  - now calls `buildReport(result, { includeDiagnostics: true })` so JSON/Markdown outputs actually include the new diagnostics data
